# VEN-STATES RP Launcher

Отдельный Windows-лаунчер проекта **VEN-STATES RP** на Tauri 2 (Rust + HTML/JavaScript).

> **Текущий статус: подготовка изолированной основы.** Лаунчер умеет запускать GTA San Andreas напрямую, но установка и обновление игровых файлов намеренно заблокированы до подключения собственного проверенного манифеста и CDN VEN-STATES. Он не должен скачивать файлы Arizona RP.

## Безопасное разделение

- Настройки VEN-STATES хранятся в `Документы/VEN-STATES RP`.
- Автоопределение ищет только отдельные папки `%USERPROFILE%/Games/VEN-STATES RP` и `%USERPROFILE%/Games/VEN-STATES`.
- Выбор папки Arizona RP блокируется; старый путь Arizona очищается только из конфигурации VEN-STATES.
- Существующая установка и кэш Arizona RP не удаляются, не перемещаются и не изменяются.
- Лаунчер не завершает процессы Arizona Launcher.
- Проверка/скачивание/установка/починка игровых файлов отключены, пока не будет настроен собственный источник файлов.

## Сборка Windows

Требуются Windows 10/11 x64, Node.js 20+, Rust stable и Microsoft C++ Build Tools.

```powershell
npm ci
npm run dev
npm run build
```

Установщик NSIS появится в `src-tauri/target/release/bundle/nsis/`.

GitHub Actions выполняет Rust-тесты и сборку на pull request в `main`, при push в `main` и по тегам релизов.

## Следующие обязательные этапы

1. Подключить собственный файл-манифест VEN-STATES и собственный HTTPS-хост файлов.
2. Проверить структуру пакета GTA SA/SA-MP и контрольные суммы всех файлов.
3. Доделать интерфейс без Arizona-новостей, модов и патчей.
4. Проверить параметры запуска и подтвердить конечный IP/порт сервера.
5. Выполнить Windows-сборку и тест установки в чистую отдельную папку.
